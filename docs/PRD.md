# 小剪 (XiaoJian) — 产品说明文档

> 一款面向普通用户的轻量级、跨平台、开源视频剪辑工具。
> 基于二次开发路线,在参考开源项目之上构建,聚焦"分段拆解 + 混合剪辑"核心场景。

| 开源协议 | 待定(见 §6) |

## 1. 一句话定位

> **"把视频拆开,再随意拼回去。"**

为非专业用户提供"剪映级别"核心剪辑体验,体积轻、上手快、纯离线。

## 2. 目标用户

| 用户画像 | 核心诉求 |
|----------|----------|
| **短视频创作者** | 快速裁切长视频、去片头片尾、提取片段发抖音/B站 |
| **口播/播客作者** | 拆音轨、删静音、改音量、导出纯音频 |
| **网课/会议剪辑** | 一键分段导出、批量命名 |
| **个人 Vlog** | 拼接多个素材 + 背景音乐 |

## 3. 核心功能(按优先级)

### P0 — MVP(首版必交付)
- [x] **F-01 视频导入**:支持 MP4/MOV/MKV/AVI/WebM;拖拽 + 点击两种方式
- [x] **F-02 分段拆解**:按时间点 / 自定义片段 / 场景检测,逐段导出
- [x] **F-03 基础剪辑**:裁剪时间线、删除区间、拼接多个片段
- [x] **F-04 音频拆分**:从视频中提取音轨(MP3/AAC/WAV),按区间切分
- [x] **F-05 混合剪辑**:替换音轨、叠加 BGM、调整音量(主轨 0-200%,BGM 0-200%)
- [x] **F-06 导出**:1080p H.264 / HEVC MP4、纯音频,质量预设 3 档

### P1 — 第二迭代

- [ ] F-09 实时预览(软件内播放)
- [ ] F-10 撤销/重做

### P2 — 远期

## 4. 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 4K 30fps H.264 切片延迟 < 2s(8GB 内存 M1/i5) |
| 体积 | 安装包 < 200MB(macOS .dmg / Windows .msi) |
| 启动 | 冷启动 < 3s |
| 隐私 | 完全离线,不上传任何数据 |
| 国际化 | 默认中文,UI 字符串走 i18n |
| 错误率 | 核心剪辑流程崩溃率 < 0.1% |

## 5. 技术选型

| 层 | 选型 | 理由 |
|----|------|------|
| **音视频引擎** | FFmpeg 6.x(静态链接) | 业界标准,处理一切格式 |
| **GUI 框架** | Tauri 2 + Web 前端 | 跨平台、产物小、JS 生态熟 |
| **前端** | React + TypeScript + Vite | 主流,招贡献者容易 |
| **状态管理** | Zustand | 轻量 |
| **后端语言** | Rust | 与 Tauri 原生搭配,FFmpeg 绑定成熟 |
| **打包** | Tauri Bundle(macOS DMG / Windows MSI) | 一键跨平台 |

## 7. 用户故事(MVP)

### US-01 分段导出
> 作为短视频创作者,**我** 想把一段 30 分钟的口播视频按"段落"切成 10 个片段,**以便于** 逐条发到平台。

**验收标准**:导入视频 → 在时间线添加 9 个分点 → 一键导出 10 个 MP4 文件,按 `原名_001.mp4` 命名。

### US-02 音频提取
> 作为播客作者,**我** 想从采访视频里提取人声轨,**以便于** 单独做转写和剪辑。

**验收标准**:导入视频 → 选 "仅导出音频" → 选 MP3 192k → 输出 1 个文件,原画质不影响。

### US-03 混合剪辑
> 作为 Vlog 作者,**我** 想用自己拍的多段素材 + 一首 BGM 合成一个完整视频,**以便于** 直接发布。

**验收标准**:导入 3 段视频 + 1 个 MP3 → 拖到时间线 → 调整 BGM 音量 30% → 导出 1080p。

## 9. 风险与决策

| 风险 | 影响 | 应对 |
|------|------|------|
| FFmpeg 静态库体积大 | 安装包超 200MB | 后期按需编入(ffmpeg.wasm 子集) |
| Tauri 2 还在 RC | 可能遇 bug | 锁定版本,准备 fallback 到 Electron |
| 实时预览性能 | 4K 卡顿 | 先做 1080p 预览,4K 仅导出 |
| 许可证合规 | 误用 GPL 代码 | 严格"借鉴思路不抄代码",CI 加 license-check |
